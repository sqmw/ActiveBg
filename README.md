## 💪 特点优势

### 轻量级设计
- 小巧的安装包
- 极低的系统资源占用

### 高度可定制
- **可扩展的资源源**
  - 支持自定义动态壁纸搜索源
  - 完全解耦的外部依赖设计
  - 便于接入不同的资源平台

- **脚本化/插件化支持**
  - 支持自定义 JavaScript 脚本
  - 可自定义 HTML 展示方式
  - 灵活的插件扩展机制
